# 後續新增測試規則

只要修改以下任一項，就必須重跑全部回歸測試：

- Julian Day 算法
- 23:00 換日規則
- 太陽視黃經公式
- 五虎遁
- 五鼠遁
- 時區處理
- 十神映射

新算法若造成既有案例失敗，不得直接更新預期答案來讓測試通過；必須先確認是舊規則錯誤、來源差異或新算法錯誤。
