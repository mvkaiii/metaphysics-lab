# 紫微流日推導測試案例

- 規則版本：v1.0-exp
- 引擎：Metaphysics Lab 紫微流日定位引擎 v1.0.0-exp
- Capability：`ziwei.flow_day_palaces`
- 狀態：Experimental / On-demand

## 基準公開案例

沿用公開流月示例：

- 出生農曆月：五月
- 出生時辰：戌
- 目標流年：酉年
- 已知依斗君法：正月流月命宮為卯

此案例只作算法回歸，不對應 repo 維護者或任何私人命主。

## Case 1｜正月初一

輸入：

```text
birth_lunar_month = 5
birth_hour_branch = 戌
flow_year_branch = 酉
lunar_month = 1
lunar_day = 1
is_leap_month = false
```

預期：

```text
流月命宮 = 卯
流日命宮 = 卯
```

理由：流月命宮起初一。

## Case 2｜正月初二

同上，只把 `lunar_day = 2`。

預期：

```text
流月命宮 = 卯
流日命宮 = 辰
```

理由：每日順行一宮。

## Case 3｜正月十三

預期：

```text
流月命宮 = 卯
流日命宮 = 卯
```

理由：十二宮循環，十三日回到初一位置。

## Case 4｜閏五月十五

輸入：

```text
lunar_month = 5
lunar_day = 15
is_leap_month = true
```

Project 流月先仍歸五月位；再以 `lunar_day - 1` 推流日。

預期：

```text
有效流月 = 5
流月命宮 = 未
流日命宮 = 酉
```

## Case 5｜閏五月十六

輸入：

```text
lunar_month = 5
lunar_day = 16
is_leap_month = true
```

Project 流月先切到下一有效月（六月位）；流日仍使用實際日數 16，不重置成 1。

預期：

```text
有效流月 = 6
流月命宮 = 申
流日命宮 = 亥
```

此為目前 Experimental 的 Project-specific leap convention；需持續接受外部排盤與 Issue 案例校驗。

## Case 6｜非法日期

`lunar_day = 0` 或 `31` 必須拋出 `ValueError`。

## Case 7｜非法地支

`birth_hour_branch = A` 必須拋出 `ValueError`。

## 外部對照

3. 易象乾坤公開排盤步驟：流月所在宮起初一，順行十二宮，一日一宮。
4. DestinyNet 舊討論中的慧心齋主著作引述：同樣以流月命宮作初一流日命宮並順行。
