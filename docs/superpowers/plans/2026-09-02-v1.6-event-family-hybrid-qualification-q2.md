# v1.6 Event-Family Hybrid Qualification Q2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立獨立、deterministic、general/synthetic-only 的 Q2 qualification authority，直接評估 EFA/C2/HCC/HOC structured outputs 是否同時保住 supported-child recall、阻止 unsupported render、正確處理 Hybrid relation/visibility，並維持 Render Manifest safety；Q2 不調整 production policy，也不宣稱能理解任意自由文字 prose。

**Architecture:** 新增獨立 evaluator `event_family_hybrid_qualification.py`，只吃 frozen structured bundles + synthetic/general expectations，驗證 source digests 與 identity 後，分層計算 Attribution / Authority / Hybrid / Render Manifest / Integrity counters，產生 aggregate-only deterministic report。另加 synthetic fixture、thin CLI 與 method doc。Production EFA/C2/HCC/HOC 全部 read-only。

**Tech Stack:** Python 3.9、stdlib `json`/`hashlib`/`argparse`、unittest/pytest、canonical JSON + SHA-256、既有 AI distribution builder。

**Spec:** `docs/superpowers/specs/2026-09-02-v1.6-event-family-hybrid-accuracy-architecture-design.md`

## Global Constraints

- 上游 EFA + C2/HCC/HOC 必須先達 `GENERAL_HOSTED_QUALIFIED` 並 frozen；Q2 不得在 production authority 還變動時寫 threshold/expectation 去追它。
- `engine/distribution/event_family_attribution.py`、`hierarchical_claim_authority.py`、`hybrid_claim_composer.py`、`hybrid_output_contract.py` 在 Q2 cycle read-only。
- Q1 與既有 T1 strict-zero policy read-only；Q2 不取代、不修改 Q1/T1。
- Q2 synthetic/general expectations 只可來自 architecture spec 與 synthetic/public/general rationale；不得讀 prior private metrics 或 exposed case labels。
- Q2 不解析 raw birth data、姓名、actual event text、free-form adjudication notes。
- Q2 不把 free-form renderer prose 當 deterministic semantic input；只評 HOC Render Manifest 與 structured child/HCC fields。
- `promotion_allowed=false` 永遠固定。
- Synthetic PASS 必須所有 negative counters = 0；blanket abstention 必須因 supported-child miss / under-render 而 FAIL。
- Private release threshold 不在本 plan 定義。
- No private Q2 run、merge、default switch、tag、release。
- TDD：先 synthetic RED，後 evaluator implementation。
