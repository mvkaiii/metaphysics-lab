# v1.6 Legacy Adapter + Paired Prospective Evaluation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立 deterministic Legacy child-level baseline projection、child-outcome oracle seal 與 paired structured comparator，讓未來全新未曝光案例能在 Legacy 與新 EFA/C2/HCC/HOC candidate 都先凍結後，以同一 sealed oracle 比較「多命中 vs 亂講」，且不靠事後解讀 prose。

**Architecture:** `event_family_legacy_adapter.py` 將 frozen legacy Interpretation v2/C1/Coordination 的 domain-level authority deterministic 投影到同一 Phase 3 child universe，故意保留 legacy breadth，而不是事後挑有利的 child。`event_family_paired_oracle.py` 定義 outcome + structural expectation 的 child-level sealed oracle/receipt。`event_family_paired_evaluation.py` 只讀 frozen Legacy projection、新 candidate HOC structured child details 與 sealed oracle，輸出 aggregate-only paired counts與 research label；不授權 release，不執行 private run。

**Tech Stack:** Python 3.9、stdlib `json`/`hashlib`/`argparse`、existing Interpretation v2/C1/Coordination/HOC contracts、unittest/pytest、canonical JSON + SHA-256、既有 AI distribution builder。

**Spec:** `docs/superpowers/specs/2026-09-02-v1.6-event-family-hybrid-accuracy-architecture-design.md`

## Global Constraints

- Q2 必須先 `GENERAL_HOSTED_QUALIFIED / Q2_FROZEN / PRIVATE_NOT_EXECUTED`；本 plan 不可在 Q2 尚可變動時建立 private paired rule。
- Legacy Adapter 只能讀 frozen structured legacy outputs；不得讀 renderer prose、private outcome 或 oracle 來選 child。
- Legacy Adapter child universe 必須與 frozen Phase 3/Interpretation event-family candidates 相同；不得新增 taxonomy。
- Legacy Adapter 的目的是忠實暴露 legacy structured parent authority 的 breadth，不是替 legacy 最佳化。
- Legacy parent `abstain_claim` 或 parent specificity < `event_family` -> baseline child `abstain_child`。
- Legacy parent renderable at `event_family` or above -> 對該 parent 所有既有 event-family candidates 做 deterministic projection。
- Legacy child caveat 直接繼承 parent C1 `render` / `render_with_caveat`，不得事後逐 child 修飾。
- Legacy relation 只做明確標記的 projection；不得假裝已取得新 EFA 的 child-level provenance。
- Paired oracle 的 child set 必須 exact-match shared frozen child universe；不允許 oracle reveal 後新增「其實還有另一種 event family」。
- Outcome oracle 不保存 raw event narrative；只存 structured status / specificity / relation / caveat expectation 與 digests。
- `indeterminate` outcome 不進 hit/false-positive denominator，也不能拿來調規則。
- Candidate/Legacy output 必須在 oracle scoring 前 sealed；future case 更必須在 outcome window 前 sealed。
- 任一 private evaluated case scoring 後永久 exposed，不得當 prospective evidence 重用。
- Private FAIL 不得用同 case retune/rerun。
- `promotion_allowed=false`；`PARETO_IMPROVEMENT_EVIDENCE` 只是 research label，不是 merge/release gate。
- 本 implementation cycle 只做 synthetic/general fixtures、seal/verify/join infrastructure 與 Hosted gate；不建立真實 private oracle、不執行 private paired evaluation。

```python
candidate_non_worse = (
    candidate["supported_child_hit_count"] >= legacy["supported_child_hit_count"]

    and candidate["specificity_overreach_count"] <= legacy["specificity_overreach_count"]

    and candidate["false_convergence_count"] <= legacy["false_convergence_count"]
```

```python
if candidate_non_worse and strict_gain:

    label = "NON_INFERIOR_NO_STRICT_GAIN"
```
