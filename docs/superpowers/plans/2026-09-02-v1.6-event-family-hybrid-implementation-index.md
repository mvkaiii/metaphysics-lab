## Self-review Correction A：EFA test helper 必須完整定義

EFA plan 中所有 synthetic tests 使用以下 test-local helper，不得留下未定義的 `structural_bundle()`：

```python
import hashlib
import json


def canonical_digest(value):
    return hashlib.sha256(
        json.dumps(
            value,
            ensure_ascii=False,
            sort_keys=True,
            separators=(",", ":"),
            allow_nan=False,
        ).encode("utf-8")
    ).hexdigest()


def structural_bundle(features, target_scope="yearly"):
    body = {
        "target_scope": target_scope,
        "features": [feature.to_dict() for feature in features],
    }
    body["interpretation_digest"] = canonical_digest(body)
    return body
```

如果現行 Structural Interpretation contract 還要求其他 frozen public fields，測試 helper 必須依現行 exact contract 補齊那些固定欄位；不得修改 production validator 來遷就簡化 fixture。

## Self-review Correction B：C2 必須有 Claim Evidence identity bridge

### 問題

Frozen C1 top-level source identity包含：

```text
claim_evidence_digest
coordination_digest
target_scope
```

EFA identity包含：

```text
base_ranking_digest
structural_interpretation_digest
target_scope
```

只給 C2 `C1 + EFA` 無法 cryptographically 證明兩者來自同一 ranking/structural source。

### Normative C2 interface

因此 C2 public API 以此為準：

```python
def build_hierarchical_claim_authority_bundle(
    *,
    claim_consumption_bundle: Mapping[str, object],
    event_family_attribution_bundle: Mapping[str, object],
    claim_evidence_bundle: Mapping[str, object],
) -> dict:
    ...
```

`claim_evidence_bundle` 在 C2 只可作 identity bridge；不得從 packet evidence 重新推導 child authority。

### Required binding checks

C2 必須先 recompute/validate Claim Evidence digest，然後：

```python
assert claim_consumption_bundle["claim_evidence_digest"] == claim_evidence_digest
assert event_family_attribution_bundle["base_ranking_digest"] == claim_evidence_bundle["base_ranking_digest"]
assert (
    event_family_attribution_bundle["structural_interpretation_digest"]
    == claim_evidence_bundle["structural_interpretation_digest"]
)
assert event_family_attribution_bundle["target_scope"] == claim_evidence_bundle["target_scope"]
assert claim_consumption_bundle["target_scope"] == claim_evidence_bundle["target_scope"]
```

C2 output 必須增加：

```text
source_claim_evidence_digest
```

並納入 `hierarchical_claim_authority_digest`。

### C2 test helper

優先用現有 builders 建合法 C1/Claim Evidence/EFA bundles。若單元測試需要直接建最小 parent bundle，helper 必須完整定義 canonical digest，不得使用未定義 `parent_bundle_with()`：


## Self-review Correction C：Divergence caveat 的 layer boundary

C2 的 normative inputs 不包含足以判斷 child-relevant divergence 的 structured conflict source；因此：

```text
C2 不猜 divergence。
HCC 讀 digest-validated frozen Claim Evidence conflict provenance。
HCC relation == divergence 時 deterministic 加 required_caveat = explicit_divergence。
HOC 必須把 explicit_divergence 帶入 Render Manifest。
```

這滿足 user-facing「divergence 必須 caveat / 不可硬統一」要求，同時不讓 C2 越權。

若未來要把 divergence caveat 前移到 C2，必須另開設計變更並修改 C2 input contract；不得在實作時偷偷加 raw evidence inference。

## Self-review Correction E：Paired research label exact algorithm

Paired plan 不得引用未定義 `candidate_has_both_better_and_worse_dimensions`。使用以下 exact comparison：

```python
better = (
    candidate["supported_child_hit_count"] > legacy["supported_child_hit_count"]
    or candidate["unsupported_child_render_count"] < legacy["unsupported_child_render_count"]
    or candidate["specificity_overreach_count"] < legacy["specificity_overreach_count"]
    or candidate["caveat_error_count"] < legacy["caveat_error_count"]
    or candidate["false_convergence_count"] < legacy["false_convergence_count"]
)

worse = (
    candidate["supported_child_hit_count"] < legacy["supported_child_hit_count"]
    or candidate["unsupported_child_render_count"] > legacy["unsupported_child_render_count"]
    or candidate["specificity_overreach_count"] > legacy["specificity_overreach_count"]
    or candidate["caveat_error_count"] > legacy["caveat_error_count"]
    or candidate["false_convergence_count"] > legacy["false_convergence_count"]
)

if better and not worse:
    research_label = "PARETO_IMPROVEMENT_EVIDENCE"
elif not better and not worse:
    research_label = "NON_INFERIOR_NO_STRICT_GAIN"
elif better and worse:
    research_label = "TRADEOFF"
else:
    research_label = "REGRESSION"
```

這等價於 spec 的「所有 comparable dimensions non-worse，至少一項 strict gain」規則，且沒有未定義 helper。
