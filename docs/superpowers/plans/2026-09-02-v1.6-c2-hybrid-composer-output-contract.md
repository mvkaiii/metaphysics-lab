# v1.6 C2 + Hybrid Claim Composer + Hybrid Output Contract Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 frozen C1 parent authority 與 frozen EFA child attribution 之下，建立 child-level C2 render authority、Hybrid Claim Composer（HCC）與 deterministic Hybrid Output Contract（HOC / Render Manifest），讓八字與紫微能 Hybrid 呈現，但 renderer 不再自行決定事件真相。

**Architecture:** C2 只決定每個既有 child 是 `render`、`render_with_caveat` 或 `abstain_child`，並以 parent C1 ceiling 與 EFA family ceiling 的最保守值限制 specificity。HCC 再對已授權 child 建立 per-child cross-system relation、parallel sibling composition group 與 inherited primary/secondary/audit visibility。HOC 將 HCC 轉成 deterministic Render Manifest；Interpretation v2 只負責接線與 expose structured authority，AI 文件則明訂只能轉譯 HOC，不得重新推導。

**Tech Stack:** Python 3.9、stdlib `json`/`hashlib`、frozen C1 + EFA bundles、Interpretation v2、unittest/pytest、deterministic canonical JSON + SHA-256、既有 AI distribution builder。

**Spec:** `docs/superpowers/specs/2026-09-02-v1.6-event-family-hybrid-accuracy-architecture-design.md`

## Global Constraints

- 必須以已 general/Hosted 凍結的 EFA candidate 為上游；若 EFA 尚未 `GENERAL_HOSTED_QUALIFIED / EFA_FROZEN`，本 plan 不得開始 production implementation。
- `engine/distribution/claim_consumption_contract.py`（C1）read-only；相同輸入下 C1 decision/digest 必須不變。
- `engine/distribution/coordination_policy_v2.py` read-only。
- Phase 3、Interpretation v1 semantics、Claim Evidence candidate universe、Q1/O1/T1/S1/I1 全部 read-only。
- C2 不得 reopen C1 `abstain_claim`。
- C2 不得新增 child；child universe 完全來自 EFA。
- C2 specificity 只能 `min(EFA family ceiling, C1 authorized specificity)`；不得升級。
- `parent authorized_specificity == "domain"` 時，即使 EFA child 有 direct support，也不得 render event family；必須 `abstain_child` 並保留 audit。
- HCC 不建立新的數值 Hybrid score；primary/secondary visibility 必須繼承 frozen Interpretation domain presentation。
- HCC 不刪除合法 renderable child；沒有 arbitrary top-N child budget。
- `parallel_sibling` 是 composition-group relation，不是單一 child 的 cross-system relation。
- HOC Render Manifest 是 deterministic renderer authority；自由文字 prose 不作為 Q2 deterministic semantic truth source。
- `causality_allowed=false` 在本 cycle 固定；不得由 renderer 自行創造因果。
- Divergence 只有在 frozen upstream structured provenance 明確 materialize 時才能出現；不同 event-family 名稱本身不算 divergence。
- 不使用 private outcomes/labels/aggregates 調整 reason code、relation precedence、visibility 或 wording rule。
- `promotion_allowed=false`；不授權 private evaluation、merge、default switch、tag、release。
- TDD 必須每個 production layer 先 RED 再 GREEN。

- [ ] **Step 6: required caveat propagation**
