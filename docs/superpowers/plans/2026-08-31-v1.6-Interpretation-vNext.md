**Goal:** 在不改寫 Phase 3 ranking authority、不新增盤面 facts 的前提下，新增 versioned Interpretation vNext：把 Bazi / Ziwei selected evidence 組成可追溯 Claim Evidence Packet，明確標記 cross-system convergence / complement / conflict、specificity ceiling、confidence 與正式 abstention，再提供 Astralium-style reading-order policy 給 AI 自然語言層使用。

**Tech Stack:** Python 3.9+、stdlib dataclasses/hashlib/json、existing `EvidenceFeature`、`rank_evidence()` output、`interpret_structural_evidence()` output、existing Phase 5 contract、`unittest`/`pytest`。

## Global Constraints

- Existing `lin_tianji_interpretation_contract_v1-exp` output/digest remains unchanged for identical v1 inputs.
- v2 profile = `lin_tianji_interpretation_contract_v2-exp`; claim packet profile = `lin_tianji_claim_evidence_v1-exp`; both remain `experimental` / `on_demand`.
- Phase 3 remains the sole base ranking authority; v2 must not add/remove/re-rank domains or event-family candidates.
- Phase 4 historical personalization may change presentation order only; it cannot create evidence, raise specificity or become chart strength.
- Structural interpretation input must be history-free and digest-valid; historical records/outcomes never enter Claim Evidence Packet generation.
- Cross-system relations are only `independent_convergence`, `layered_complement`, `conflict_or_divergence`; when only one system contributes, `cross_system_relation = None` and existing `single_system_support` semantics apply.
- `independent_convergence` is evidence clarity, not probability.
- `conflict_or_divergence` must preserve both Bazi and Ziwei evidence and a machine-readable reason; AI may not silently choose one side.
- Confidence classes are `high_confidence | moderate_confidence | low_confidence`; they are epistemic labels, not event likelihoods.
- Specificity authority remains Phase 3 + existing local-window cap. v2 may only preserve or lower specificity.
- Formal abstention labels are `abstain_domain`, `abstain_event_family`, `abstain_timing`, `abstain_concrete_event`.
- Reading-order policy never claims unavailable computations. `格局 / 月令用神 / 扶抑 / 調候 / 病藥 / 通關 / 神煞` may be interpreted only when materialized by a supplied authoritative source; absence requires omission/abstention, not free calculation.
- Bazi five-element counts alone never establish Day Master strength; Ten-God names never directly equal concrete events; Shensha are auxiliary only.
- Ziwei fine-cycle layers are usable only when already materialized by runtime and allowed by maturity/routing; Bazi conclusions may not rewrite Ziwei facts or vice versa.
- No probability fields, percentages, numeric likelihood or accuracy estimates in runtime interpretation output.
- Existing Case Schema 1.1 and Project Contract 1.1 remain unchanged in this plan.

Rules:

```text
independent_convergence:

None:
  only one system contributes, or there is no actual cross-system relationship to classify.
```

### Task 4: Add specificity-aware confidence and abstention

**Files:**
- Modify: `engine/distribution/claim_evidence.py`
- Modify: `tests/test_distribution_claim_evidence.py`

**Interfaces:**

```python
def confidence_class_for_packet(packet_inputs: Mapping[str, object]) -> str: ...
def abstentions_for_packet(
    *,
    effective_specificity: str,
    event_family_candidates: Sequence[str],
    has_local_window: bool,
    cross_system_relation: str | None,
) -> list[str]: ...
```

Confidence rules are deterministic and non-probabilistic:

```text
low_confidence when:
- cross_system_relation == conflict_or_divergence; OR
- effective_specificity == domain; OR
- every selected target evidence item is experimental / needs_verification.

high_confidence when:
- cross_system_relation == independent_convergence; AND
- every selected target evidence item is qualified; AND
- at least one selected target evidence item is stable; AND
- effective_specificity is event_family or concrete_event.

moderate_confidence otherwise.
```

Abstention rules:

```text
abstain_event_family      if effective_specificity == domain or event_family_candidates is empty
abstain_timing            if no applicable local window exists for the packet
abstain_concrete_event    unless effective_specificity == concrete_event
abstain_domain            is top-level only when base ranking has no opened domains
```
