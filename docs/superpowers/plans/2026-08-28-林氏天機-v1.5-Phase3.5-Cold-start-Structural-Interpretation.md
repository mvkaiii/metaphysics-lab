```python
class BaziStructuralRelationTests(unittest.TestCase):

        self.assertFalse(any(row.relation_family == "stem_repeat" for row in repeated_year))

        natal = {"year": "甲子", "month": "乙丑", "day": "丙寅", "hour": "丁卯"}
        yearly = detect_structural_relations(
            scope="yearly",
            target_pillar="戊辰",
            natal_pillars=natal,
            decadal_pillar="戊辰",
        )
        monthly = detect_structural_relations(
            scope="monthly",
            target_pillar="戊辰",
            natal_pillars=natal,
            decadal_pillar="戊辰",
        )
        self.assertIn("sui_yun_bing_lin", {row.relation_family for row in yearly})
        self.assertNotIn("sui_yun_bing_lin", {row.relation_family for row in monthly})

    def test_output_order_is_canonical(self):
        kwargs = dict(
            scope="yearly",
            target_pillar="庚申",
            natal_pillars={"hour": "乙亥", "day": "甲寅", "month": "戊午", "year": "丙申"},
            decadal_pillar="壬子",
        )
        first = detect_structural_relations(**kwargs)
        second = detect_structural_relations(
            **{**kwargs, "natal_pillars": dict(reversed(list(kwargs["natal_pillars"].items())))}
        )
        self.assertEqual(first, second)
```

- [ ] **Step 4: Implement one canonical Bazi aggregate feature per scope/domain**

Create `engine/distribution/bazi_structural_interpretation.py`. The central function must:

1. Strictly validate forecast context top-level keys used by this layer; reject `historical_records`, `actual_event`, `known_event_years` if present anywhere in the accepted public context envelope。
2. Read `bazi.structural_context.natal_pillars` and stored `current_decadal` from Task 1；never infer a missing luck period。
3. Build an implicit decadal scope feature when `current_decadal` exists and target scope is decadal-or-finer, even if Ziwei requested scopes omitted `decadal`, because the spec requires current Bazi luck as coarser modifier context。
4. For each requested target/fine Bazi scope, call `detect_structural_relations()` using that scope’s stored target pillar；for yearly pass `decadal_boundary=bool(decadal_boundaries_in_flow_year)`。
5. Determine feature strength as max closed strength class among canonical relations；no relation = `unspecified`。
6. Event-family set = ten-god base families + closed relation overlay; no concrete event words。
7. Emit exactly one `EvidenceFeature` per `(scope, primary_domain)` with dependency family `bazi.structural:<scope>:<pillar>:<domain>`。
8. Preserve canonical relation rows in provenance as structured data, not free text。
9. Use `maturity="experimental"` for Phase 3.5 Bazi interpreted features; qualification is `needs_verification` when target Bazi boundary warning applies, otherwise `qualified`。
