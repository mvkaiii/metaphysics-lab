# 紫微流時 Capability Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不處理民用 datetime、時區、國曆轉農曆與日界政策的前提下，完成可重現的紫微流時命宮＋流時十二宮 capability，並將其標記為 `implemented / experimental / on_demand`。

**Architecture:** 採已核准的 1.5 架構：人類／AI 友善輸入未來由 Calendar / Input Resolver 解析；`engine/ziwei/hour.py` 只接受已確認的農曆日期與 `hour_branch`。流時核心依賴既有 `engine.ziwei.day`，用 `flow_hour_index = (flow_day_index + hour_branch_index) mod 12` 推導流時命宮，再共用 `palaces_from_ming_branch()` 重排十二宮。

**Tech Stack:** Python 3.9+、標準函式庫 `unittest` / `argparse` / `json`、既有 `engine.ziwei` 模組；不新增第三方 runtime dependency。

**Spec:** `docs/superpowers/specs/2026-08-20-紫微流時能力設計.md`

## Global Constraints

- Capability ID 固定為 `ziwei.flow_hour_palaces`。
- 第一版 maturity 固定為 `experimental`，routing 固定為 `on_demand`，rule version 固定為 `1.0-exp`。
- `hour.py` 不解析 `14:00`、`下午兩點`、timezone、DST、國曆日期，也不自行判斷 23:00 換日。
- `hour.py` 只接受已確認 `hour_branch`，且必須是 `子丑寅卯辰巳午未申酉戌亥` 之一。
- 不實作流時天干、流時四化、流曜、細層飛化、Calendar Resolver、Cross-System Validation。
- Experimental capability 不加入 `engine.ziwei` root eager export；由 `engine.ziwei.hour` 明確 import。
- 所有輸出必須標示 `classification = Project 推導盤面`，不得冒充 Astralium、iztro 或其他第三方直接輸出。
- 至少完成兩個可信外部來源的流時起法交叉驗證後，才能把 registry 從 `planned` 改成 `implemented / experimental`。
- 不使用任何真實命主私人出生資料做 repo 測試。

`engine/ziwei/hour.py` 的核心邏輯應直接是：

```python
from .capabilities import get_capability
from .common import ZHI, palaces_from_ming_branch, validate_branch
from .day import flow_day_ming_branch
from .month import effective_lunar_month, flow_month_ming_branch

CAPABILITY_ID = "ziwei.flow_hour_palaces"


def flow_hour_ming_branch(
    birth_lunar_month: int,
    birth_hour_branch: str,
    flow_year_branch: str,
    lunar_month: int,
    lunar_day: int,
    is_leap_month: bool,
    hour_branch: str,
) -> str:
    validate_branch(hour_branch)
    day_branch = flow_day_ming_branch(
        birth_lunar_month,
        birth_hour_branch,
        flow_year_branch,
        lunar_month,
        lunar_day,
        is_leap_month,
    )
    return ZHI[(ZHI.index(day_branch) + ZHI.index(hour_branch)) % 12]


def flow_hour_palaces(ming_branch: str) -> dict[str, str]:
    return palaces_from_ming_branch(ming_branch)
```
