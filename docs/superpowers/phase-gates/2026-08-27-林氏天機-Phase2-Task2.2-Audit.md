# 林氏天機 Phase 2 Task 2.2 稽核補強紀錄

日期：2026-08-27

## 稽核邊界

Task 2.2 的輸入契約維持既有 deterministic forecast context。Evidence adapter 只能正規化 forecast runtime 已 materialize 的資料，不得繞過 forecast context 去 natal 或其他來源補造 evidence。

## Raw provenance

Bazi evidence 必須和 Ziwei evidence 一樣保留可追溯的 raw source record。`provenance.source_record` 保存當次 `forecast_context["bazi"]` 的 detached JSON-safe snapshot；原有 adapter、mapping profile、pillar、ten-god 等 convenience fields 保留，方便檢索與除錯。

這項補強不得改寫 upstream calculation truth，也不得改變 maturity、qualification、domain mapping 或 role policy。

## Decadal 與 major_cycle 邊界

目前 forecast runtime 的正式運限 scope 是 `decadal`。當 target 是 yearly 或更細時間層時，`decadal` evidence 的 role 為 `modifier`，並以 regression test 固定此契約。

`major_cycle` 目前只存在於 EvidenceFeature 的模型 vocabulary／保留 scope，尚未由現行 forecast context materialize。Task 2.2 不得為了產生 `major_cycle` feature 而自行讀取 Bazi natal 大運或其他不在 forecast context 的資料。未來若 upstream forecast contract 正式提供 `major_cycle`，再以獨立設計審查與測試納入 adapter。

## Phase 邊界

本補強不新增也不調整 weight、score、rank、probability、eligibility 或 specificity policy。這些仍屬 Phase 3。
