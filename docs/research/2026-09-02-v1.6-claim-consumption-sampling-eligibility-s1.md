# v1.6 Claim Consumption Sampling Eligibility S1

## Status

S1 是 general-only、prospective-only 的 Complete-Census sampling authority。它的工作是證明一個事前鎖定的 private sampling frame 是否完整涵蓋 source manifest 中所有 cases，並且只有符合 frozen eligibility rules、尚未暴露、具有 outcome-free claim universe 的 cases 才能成為 `INCLUDE`。

正式 profile：`lin_tianji_claim_consumption_complete_census_v1`。

`promotion_allowed=false`。

## Complete census

Complete census 不是抽樣率。每個 source-manifest case 必須在 sampling frame 中恰好出現一次；S1 不接受 discretionary exclusion，也不接受 frame 偷刪 case 後只靠 counts 宣稱完整。

固定 exclusion precedence：after cutoff → Previously exposed → non-confirmation → input invalid → out of scope → INCLUDE。相同 eligibility facts 必須產生相同 status / reason。

## Prospective sequence

唯一合法順序：

`T1 policy freeze -> S1 protocol freeze -> source manifest lock -> outcome-free claim universe lock -> sampling frame lock -> sampling receipt -> claim adjudication -> oracle identity verification -> O1 seal -> candidate -> Q1 exactly once -> T1 gate`

S1 本身 does not execute Q1，也 does not execute T1。

## Previously exposed

Previously exposed cases 永久排除，不能透過換 case ID、digest、branch 或重跑 candidate 恢復 eligibility。exposure fact 必須在 sampling frame lock 前固定，而且不能根據即將評估 candidate 的輸出決定。

## Outcome-free claim universe

Outcome-free claim universe 只鎖 claim identity，不鎖 `render / render_with_caveat / abstain_claim` 或 specificity answer。Claim authority 不得讀 verified outcome、C1 render decision、Q1 result 或候選輸出後的人工作業。

S1 identity verifier 只比較 oracle case/claim identity set 是否與 sampling INCLUDE set 完全相等，不評 oracle answer semantics。

## Public / private boundary

Public repo 可保存 protocol、general source/test/docs 與 aggregate/digest-only receipts。Real private source manifest、opaque case IDs、real claim IDs、sampling frame、adjudication notes、oracle answers、candidate private output 與 joined Q1 input全部留在 git 外。

Private CLI modes要求 explicit `--output`；工具不會搜尋、補齊或自動選 cases。

## Release boundary

Sampling receipt `ELIGIBLE` 只表示 prospective complete-census sampling evidence合格，不代表 Q1 PASS、T1 PASS、merge、default switch、tag 或 release。所有 S1 public artifacts / receipts保留 `promotion_allowed=false`。
