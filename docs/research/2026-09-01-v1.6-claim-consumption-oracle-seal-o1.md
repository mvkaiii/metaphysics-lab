# Metaphysics Lab v1.6｜Claim Consumption Oracle Seal O1 方法與治理紀錄

## 目的

O1 建立的是 claim-level oracle 的 evaluation-integrity 基礎設施：先在 candidate scoring 之前封存 expectations 與 case-set identity，之後才將同一份 sealed oracle 與 frozen candidate 的 C1 output 組合成既有 Q1 qualification input。O1 不改 C1 policy，也不改 Q1 scoring。

## Governance locks

`PRIVATE_ORACLE_OUTSIDE_GIT`

Private oracle、private seal、candidate-output package 與 joined Q1 private input 都必須留在 git 外。Repo 可保存的只有不含 case/claim answers 的 aggregate seal receipt。

`CANDIDATE_OUTPUT_AFTER_FREEZE`

Candidate output 只能在 candidate SHA 已獨立 freeze 且完成 Project 要求的 general/Hosted qualification 後匯出。Oracle expectations 不得在看到 candidate output 後修改。

`JOIN_DOES_NOT_SCORE`

Join 只驗證 seal、candidate identity、case/claim sets，組裝既有 Q1 input 並呼叫 frozen Q1 validator；join 不呼叫 Q1 evaluator，也不產生 private performance result。

`PRIVATE_Q1_NOT_EXECUTED`

O1 開發 cycle 只使用 synthetic/general fixtures。本 cycle 不建立真實 private oracle、不執行 private Q1 evaluation，也不使用既有 private aggregate outcome 調整 O1 policy。

`promotion_allowed=false`

Seal receipt、O1 qualification 與任何未來 private metrics 都不能自行授權 promotion、merge、default switch、tag 或 release。

## Seal workflow

1. 先 freeze adjudication rubric identity。
2. 在沒有 candidate output 的情況下建立 claim-level expectations。
3. 驗證 oracle schema 與 case/claim digests。
4. 建立 deterministic seal；private oracle 與 seal 留在 git 外。
5. 如需公開稽核，只輸出 aggregate-only receipt。
6. 獨立 freeze candidate SHA，完成 local + Hosted general gates。
7. 對同一 opaque case set 匯出 candidate C1 output。
8. 驗證 oracle seal 與 candidate-output package。
9. Join 成 frozen Q1 input schema；此步只 validation，不 scoring。
10. 未來若另有授權，才對 valid sealed oracle + frozen candidate pair 執行一次 Q1 private evaluator。

## Privacy boundary

所有 O1 schema 都採 strict allowlist；unknown fields 一律 fail closed。Public receipt 與 verification report 只允許 aggregate identity/status，不得序列化 case-level expectations、claim answers、個人資料或敘事式 adjudication。

## Failure semantics

- seal verification failure：停止，不得 join。
- contamination count 非零：停止，不得 join。
- candidate case/claim identity mismatch：停止，不得 join。
- joined Q1 validator failure：在任何 private scoring 前先修 infrastructure/contract。
- 若未來已對某一 valid candidate/oracle pair 執行 private evaluation，該 pair 不得在同一 cycle 重跑並據結果修改 oracle、C1、Q1 scoring 或 thresholds。

## O1 local / Hosted gates

General-qualified O1 必須通過：synthetic seal/verify/join tests、tamper tests、privacy/unknown-field rejection、frozen Q1/C1 regression、formal AI builder parity、full repository regression、Python 3.9 compile、clean tree，以及 Hosted same-SHA validation。

這些 general gates 不需要也不允許用 private result 補足。
