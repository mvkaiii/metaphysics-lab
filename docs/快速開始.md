# 快速開始

## 1. 先建立私人個案空間

Metaphysics Lab Core 與個人資料要分開。請在私人環境建立自己的 Case，不要把真實命主資料直接提交到這個儲存庫。

建議至少建立：

- 命盤核心摘要.md
- 命盤資料校驗紀錄.md
- 驗證事件紀錄.md
- 流年追蹤紀錄.md
- 問事追蹤紀錄.md
- 重大決策紀錄.md

可直接複製 `templates/` 內的空白模板。

## 2. 建立與校驗命盤

先確認出生日期、時間、地點、時區、採用時辰與不同排盤來源的口徑，再把穩定結論寫入核心摘要。

若不同來源有真太陽時、子時換日、起運算法或其他差異，應寫入命盤資料校驗紀錄，不要直接互相覆蓋。

## 3. 問未來問題時先盲判

流年問事與行動決策先讀：

- 命理分析作業規範
- 命盤資料校驗紀錄
- 命盤核心摘要
- 八字／紫微正式盤面
- 命理推導計算規則

第一版盤面判斷完成以前，不先讀既有驗證事件。

## 4. 需要月份／日期／時辰時

使用 `engine/project_bazi_calendar.py` 建立 Project 推導盤面。

例如：

```bash
python engine/project_bazi_calendar.py "2026-08-20 17:12" --tz Asia/Taipei --day-master 丙 --pretty
```

輸出屬於 Project 推導盤面，不是第三方排盤系統的直接輸出。

## 5. 第二階段再做事件校準

第一版盲判鎖定後，才讀驗證事件紀錄，用來判斷同類訊號在命主身上的實際落地方式與信心。

不得用已知事件反向修改第一版盲判。
