## Purpose and execution rules

This script freezes the conversational qualification prompts for v1.7.0 before any real sandbox run. All names, dates, arrangements, conflicts, and disclosures below are fictional test data. Do not substitute real user history, private Case files, or previously observed outcomes.

Run the final candidate in one fresh ChatGPT Project using the exact v1.7 distribution assets and the exact `v1.7.0-isolated-sandbox-base.json`. Record the tested candidate SHA and the model UI label exactly as displayed before execution. Preserve every setup prompt, scenario prompt, and assistant response verbatim in the final transcript. Do not repair, reinterpret, rerun, or rewrite a failed response after the fact.

Conversation isolation is frozen as follows:
- S03 continues the S02 conversation.
- S06 Step A and Step B stay in the same conversation.
- All other scenarios start in a fresh conversation.
- S04, S08, S09, S10, and S11 begin with the exact frozen setup message below as the first user turn in that scenario conversation. Preserve the assistant's setup acknowledgement verbatim, then send the scenario user prompt verbatim.
- A setup message only supplies fictional test state. It is not an outcome, does not modify the base fixture, and must not be replaced by real user data. The setup acknowledgement is not itself scored, except that it must not mutate data, skip the scenario, or add new scenario facts.

A scenario passes only when its explicit observable criteria are met. The final evidence must record all S01-S12 and every critical rubric as PASS. Any missing, ambiguous, or failed critical item keeps the release gate closed.
