# MingStack v1 架構設計

## 定位

MingStack 是一套以「可重現、可驗證、以決策為導向」為核心的命理分析框架。

它不是單一命主的命盤資料夾，也不是單純的算命提示詞集合。MingStack 將命理分析拆成可管理的層級：

1. 原始盤面資料
2. 資料校驗
3. 固定算法推導
4. 第一階段盲判
5. 第二階段事件校準
6. 現實決策策略
7. 後續結果驗證

## 核心原則

- 命盤提供模型。
- Project 推導提供時間層級。
- 事件提供證據。
- 現實背景決定策略。
- 問事先盲判，再校準。
- 原始盤面、Project 推導盤面與命理推論必須分開。
- 個人資料與系統核心必須分開保存。

## 儲存庫邊界

本儲存庫只保存可共用的系統核心，不保存任何實際命主的私人資料。

不得提交：

- 真實姓名與可識別身分資訊
- 出生年月日時與出生地的真實個案資料
- 個人八字／紫微原始資料包
- 醫療、家庭、工作、資產與感情事件紀錄
- 實際問事紀錄與重大決策紀錄

這些資料應保存在使用者自己的私人 Case／ChatGPT Project／其他私有知識庫中。

## 元件責任

### core

保存分析規範、推導規則與系統提示詞。這些文件定義「應該怎麼分析」與「哪些計算可以被視為正式 Project 推導」。

### engine

保存可執行的時間推導程式。目前 v1 僅啟用子平八字流年、流月、流日、流時與天干十神。紫微細運尚未啟用。

### tests

保存自動測試與人工可閱讀的回歸測試紀錄。任何曆法、換日、節氣、時區、五虎遁、五鼠遁或十神映射變更，都必須先通過既有測試。

### templates

只保存空白模板，供新命主建立自己的私人 Case。模板不得包含任何既有命主的真實資料。

### docs

保存一般使用者可閱讀的導覽、架構與資料治理說明。

## 版本策略

採語意化版本概念：

- 主版本：架構或相容性重大變更
- 次版本：新增可用功能但維持既有相容性
- 修訂版本：修正錯誤或文件，不改變主要介面

MingStack Core 與各計算引擎可分開標示版本，但 VERSION.md 必須列出目前正式組合。

## v1 範圍

正式納入：

- 命理分析作業規範
- 問事雙階段流程
- Project 八字時間推導規則
- Project Bazi Calendar Engine v1.0.0
- 流年／流月／流日／流時
- 23:00 換日
- 五虎遁／五鼠遁
- 天干十神
- 節氣邊界警告
- 空白個案模板
- 版本與變更管理

暫不納入：

- 紫微流月／流日／流時推導
- 完整 Project 干支互動引擎
- 奇門自動排盤引擎
- 真實個案資料
- 醫療、法律、財務專業決策替代功能

## 發布原則

使用者升級 MingStack 時，只更新核心、引擎、測試與模板；自己的私人 Case 不應被更新程序覆蓋。
