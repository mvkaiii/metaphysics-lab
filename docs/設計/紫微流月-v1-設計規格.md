# 紫微流月 v1 設計規格

## 目標

在 MingStack 啟用「紫微流月」的 Project 推導能力，但只做到月份層級，不啟用紫微流日、流時、流月四化、流月流曜或更細的飛化。

## 正式範圍

v1 只提供：

- 流年斗君定位
- 流月命宮定位
- 流月十二宮重排
- 一般農曆月邊界
- 閏月邊界
- 明確標示與八字流月的差異

v1 不提供：

- 紫微流日
- 紫微流時
- 流月四化
- 流月流曜
- 流月宮干飛化
- 自動從國曆換算農曆日期

## 流派與算法

採斗君流月法：

1. 以目標流年地支所在宮起正月。
2. 逆數至命主出生農曆月。
3. 由該宮起子時，順數至出生時辰，所得宮位為該流年的斗君。
4. 斗君所在宮為正月流月命宮。
5. 其餘月份每月順行一宮。

程式索引以地支順序「子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥」表示。

## 流月十二宮

得到流月命宮後，依紫微十二宮固定次序重排：

命宮、兄弟宮、夫妻宮、子女宮、財帛宮、疾厄宮、遷移宮、交友宮、官祿宮、田宅宮、福德宮、父母宮。

以流月命宮為起點，後續宮位依本命十二宮配置相同方向逆地支排列。

## 月份邊界

### 一般月份

紫微流月採農曆月，不採八字節氣月。

- 農曆初一切換月份。
- 不以立春、驚蟄、清明、立夏等節氣切換紫微流月。
- 同一天的八字流月與紫微流月可能不同，屬正常設計，不是 bug。

### 閏月

MingStack v1 固定採「閏月拆半」：

- 閏月初一至十五：歸前一個月位。
- 閏月十六至月底：歸下一個月位。

此為 MingStack 固定口徑。其他排盤系統可能把整個閏月視為獨立月份或採其他規則；結果不同時應先檢查流派與閏月規則，不直接判定程式錯誤。

## 輸入邊界

引擎只負責紫微流月定位，不負責國曆轉農曆。

正式輸入：

- 出生農曆月：1–12
- 出生時辰地支：子丑寅卯辰巳午未申酉戌亥
- 目標流年地支
- 目標農曆月：1–12
- 目標農曆日
- 是否閏月

若呼叫端只有國曆日期，必須先由可信曆法來源完成農曆日期轉換，再傳入本引擎。不得由模型憑記憶猜農曆月份。

## 輸出

輸出至少包含：

- 引擎名稱與版本
- 分類：Project 推導盤面
- 規則：斗君流月
- 月份邊界：農曆初一；閏月拆半
- 流年斗君地支
- 有效流月月份
- 流月命宮地支
- 流月十二宮對應地支
- 邊界說明
- 明確聲明：不是 Astralium 直接輸出

## 問事使用方式

月份級問事可使用：

- 八字：本命 → 大運 → 流年 → 節氣流月
- 紫微：本命 → 大限 → 流年 → 小限 → Project 紫微流月

八字流月主要看月份五行、十神與時間壓力；紫微流月主要補充事情更可能落在哪個人生領域。

兩套流月的月份邊界不同，不能互相取代或要求逐日同步。

## 版本邊界

v1 啟用紫微流月後，文件必須寫成：

- 紫微流月：已啟用
- 紫微流日：未啟用
- 紫微流時：未啟用
- 流月四化／流曜／細層飛化：未啟用

不得再用「紫微細運全部未啟用」這種模糊描述。
