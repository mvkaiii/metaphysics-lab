# 資料治理

## 系統核心與私人資料分離

本儲存庫只保存共用規則、引擎、測試與空白模板。

私人 Case 不應提交到本儲存庫。

## 不應提交的資料

- 真實姓名與可識別資料
- 真實出生年月日時與出生地
- 個人八字、紫微原始資料包
- 醫療事件
- 家庭事件
- 工作與收入事件
- 資產與投資事件
- 感情與婚姻事件
- 真實問事紀錄
- 重大決策紀錄

## 原始來源與推導結果

第三方來源直接提供的欄位稱為「原始盤面事實」。

依 Metaphysics Lab 固定算法自行計算的資料稱為「Project 推導盤面」。

對盤面的解讀稱為「命理推論」。

三者不得混稱。

## 驗證事件

驗證事件只保存真正已發生或已確認的事情。未來計畫、命理推論與預測不得提前寫成已驗證事件。
