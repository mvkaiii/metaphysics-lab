# Metaphysics Lab v1.7.1 發布說明

## 版本定位

Metaphysics Lab v1.7.1 是 **release identity metadata patch**。它不是新的命理算法版本，也不做 capability promotion；主要修正 v1.7.0 使用者最容易混淆的一件事：整體 Metaphysics Lab Release 版本與內部 AI Distribution Runtime 版本原本沒有在 `runtime_info` 同時顯示。

v1.7.1 正式版本層級：

```text
Release Version            1.7.1
Project Contract           1.2
Runtime Schema             1.1
Case Schema                1.1
AI Distribution Runtime    1.2-exp
Capability Manifest        1.0
```

因此看到 `release_version = 1.7.1` 與 `distribution_runtime_version = 1.2-exp` 同時存在是正常的；兩者不是互相衝突的版本號。

## 這次改了什麼

### runtime_info 新增 Release identity

`runtime_info` 現在新增：

```text
release_version: 1.7.1
```

原本的欄位全部保留，例如：

```text
distribution_runtime_version: 1.2-exp
project_contract_version: 1.2
runtime_schema_version: 1.1
case_schema_version: 1.1
```

這讓 AI 可以直接說：

> 目前安裝的是 Metaphysics Lab v1.7.1 Release，其中 AI Distribution Runtime 版本為 1.2-exp。

而不需要再從 README / VERSION.md 反推整體 Release 名稱。

### Release / package version 使用同一個 authority

User Package 名稱改由同一個 `RELEASE_VERSION` authority 產生：

```text
Metaphysics-Lab-v1.7.1-User-Package.zip
```

避免 release 文件、package builder 與 runtime metadata 分別維護不同版本字串。

## 從 v1.7.0 升級

如果目前已經安裝 v1.7.0，這次是 **Runtime-only patch**：

1. 到正式 GitHub Release `v1.7.1`。
2. 下載新版 `metaphysics_lab.py`；也可以下載 `Metaphysics-Lab-v1.7.1-User-Package.zip` 後只取出該檔。
3. 在原 Project **只替換 `metaphysics_lab.py`**。
4. `metaphysics_core.md` 不需要替換。
5. Project Instructions 不需要重新貼。
6. `命主索引.md`、私人 Case、命盤資料、驗證事件、流年／問事／重大決策紀錄與所有已鎖定預測全部保留。
7. 執行 `runtime_info`，確認：
   - `release_version = 1.7.1`
   - `distribution_runtime_version = 1.2-exp`
   - `project_contract_version = 1.2`
   - `runtime_schema_version = 1.1`
   - `case_schema_version = 1.1`

### 舊 Case metadata 不需要批次改寫

v1.6 或 v1.7.0 時期建立的 Case 可能仍保存：

```text
project_contract_version: 1.1
runtime_version_if_applicable: 1.1-exp
```

這些欄位可以是建立／修改當時的歷史 provenance。v1.7.1 **不要求為了看起來像新版而批次覆寫 Case front matter**。

只要 Case Schema 1.1 能被新版 runtime 正常 validate，就不是升級失敗。

## 從 v1.6.0 或更早版本升級

若目前還不是 v1.7.0，請先依 v1.7.0 的升級規則同步三個發行檔案：

```text
metaphysics_lab.py
metaphysics_core.md
project_instructions.txt
```

再確認最後的 runtime 是 v1.7.1。

## 不會因本 patch 改變的內容

v1.7.1 不修改：

- 八字／紫微計算公式
- Calendar / Ziwei boundary profile
- Case Schema
- Project Contract
- Runtime Schema
- selector v1 default
- interpretation v1 default
- Prospective Validation 2.0 的分類規則
- Guided Inquiry 的 evidence / specificity 邊界
- 任何 capability 的 implementation / maturity / routing

紫微流日、流時、流曜等原本屬於 **Experimental / on-demand** 的能力仍然維持原狀；v1.7.1 不代表它們變成 Stable，也不代表已證明比舊方法更準。
