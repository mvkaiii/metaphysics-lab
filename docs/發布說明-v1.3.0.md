# Metaphysics Lab v1.3.0

發布日期：**2026-08-23**

這份是給一般使用者看的發布說明。完整 qualification、Phase 歷史、測試數量與技術狀態請看 `CHANGELOG.md` 與 `VERSION.md`。

## 這版主要有什麼？

v1.3.0 把命盤建立、紫微細時間計算與 AI Project 使用方式整理成一個正式版本。

一般使用者最直接會感受到：

- 可以從出生資料建立 Project 八字與紫微本命盤。
- 有 Astralium 或其他第三方排盤時，可以一起做交叉校驗；沒有第三方盤也能使用。
- 加入更細的紫微時間層與流曜相關計算，實際可用範圍由系統判斷。
- 正式提供 ChatGPT Project / Claude Project 使用的三個檔案。
- 出生資料不完整時不應自行猜出生時間、地點或其他缺值。
- Python 負責固定計算，AI 負責解讀與策略分析。

## 一般使用者下載

到 GitHub Release 頁面下方的**下載區（GitHub 顯示為 Assets）**，下載下面三個檔案即可。

**不需要下載 Source code，也不需要解壓縮原始碼。**

| 用途 | 實際檔名 | 使用方式 |
|---|---|---|
| **命理計算程式** | `metaphysics_lab.py` | 上傳到 ChatGPT / Claude Project |
| **命理分析核心規則** | `metaphysics_core.md` | 上傳到 Project |
| **Project 設定指令** | `project_instructions.md` | 全文貼到 Project Instructions |

> **2026-08-24 檔名整理：**兩個 Markdown 發行檔統一改成全小寫檔名，並只同步其內部檔名引用；`metaphysics_lab.py`、v1.3.0 版本標籤與命理能力沒有因此改版。

設定完成後，直接對 AI 說：

> **「開始建立我的命理專案。」**

如果平台提供**較高推理強度**或深度思考模式，完整本命、流年、合盤或重大決策分析可優先使用。

## 命盤資料可以怎麼提供？

### 只有出生資料

提供性別、出生日期、出生時間與出生地，由 Metaphysics Lab 建立 Project 原生命盤。

### 出生資料 + Astralium

如果有 Astralium 八字／紫微或其他第三方排盤，可以一起提供做交叉校驗。

Astralium 是**可選**來源，不是安裝或使用 Metaphysics Lab 的必要條件。

### 只有第三方排盤

如果目前只有 Astralium、其他排盤網站、命理軟體或命理師提供的結構化命盤，也可以先匯入 External 資料；系統不會因此假裝自己已完成 Project 原生計算。

## Astralium 在這套系統裡扮演什麼角色？

Astralium 可以提供八字與紫微的第三方資料。Metaphysics Lab 會把第三方資料與 Project 自己計算的結果分開保存，再比較是否一致。

有差異時會保留差異，不會為了讓結果看起來一致而覆寫任何一方原始資料。

詳細方式見：`docs/Astralium資料取得指南.md`。

## 出生時間不確定

如果只知道一段時間範圍，系統不應自行補成區間中點或任意時辰。資料足夠時，可以保留多個候選狀態，只使用所有候選都一致的部分。

詳細方式見：`docs/命盤資料準備指南.md`。

## 技術狀態

v1.3.0 是正式 GitHub Release，但**正式發版不等於所有新能力自動升為 Stable**。部分能力仍處於實驗或按需使用狀態。

一般使用者不需要自己判讀能力表；技術上目前實際可執行的能力以 `runtime_info` 為準，完整版本紀錄見 `VERSION.md`。
