# Metaphysics Lab v1.8.0｜發布說明

> 發布日期：**2026-09-30**  
> 正式版本：**v1.8.0**  
> 正式發布提交：`63b9d10b66f24775c86249c90f37175bd3067f0f`

v1.8.0 是向後相容的小版本更新。這一版主要改善八字大運時間計算的可追溯性、加入大運視覺化功能，並把一般命理解讀改成預設精簡呈現。這些更新**不會把仍在實驗階段的功能自動升級為穩定狀態，也不會更動目前的預設選擇與解讀機制**。

## 使用者會感受到的改變

### 1. 八字大運時間來源更清楚

Bazi Calendar Engine 已升為 1.1.0，節氣資料採用 Project 內建的 `lunar-python==1.4.8` JieQi table。

大運起運邊界固定為：

- 順推：第一個 `Jie >= birth_datetime`
- 逆推：最後一個 `Jie <= birth_datetime`

Project 已保存的香港天文台（HKO）基準測試涵蓋 48 個節氣點，全部落在公布的 60 秒精度範圍內。

### 2. 新增八字大運時間軸

v1.8.0 的使用者安裝包新增公開功能 `render_bazi_decadal_timeline`。

它可以把已建立的 Project 原生命盤或標準化本命資料轉成：

- 可重現的 SVG 大運時間軸
- 純文字替代版
- 同一份 Chart Contract 對應的結構化資料

這個圖表功能目前仍屬**實驗性呈現功能**。它不會提升 `bazi.natal_chart` 的成熟度，也不會新增任何預測證據。

### 3. 一般回答預設更精簡

一般命理對話改採「**預設精簡，需要時再展開細節**」的方式：

- 一般問題先呈現核心判斷、必要圖表與少量行動建議。
- 使用者追問原因時，再展開命理依據與證據。
- 技術稽核內容只在真正的開發或驗證情境中顯示。

這項調整只改變**呈現方式**，不改變盤面計算、判斷排序、證據使用、結論具體程度、信心或盲判流程。

## 升級時要注意什麼

從 **v1.7.1 升到 v1.8.0**，請三檔一起同步：

1. `metaphysics_lab.py`
2. `metaphysics_core.md`
3. `project_instructions.txt`

既有的 `命主索引.md`、私人 Case、驗證事件、流年／問事／重大決策紀錄與已鎖定預測都應保留。

因八字本命與大運的時間計算方式已有實質工程修正，既有已產生的八字長週期資料不得直接覆寫。若要使用新版執行程式重新計算，應採明確的重新計算與校驗流程，並保留舊版資料的來源與版本紀錄。
