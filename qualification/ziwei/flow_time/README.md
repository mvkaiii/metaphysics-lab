This directory records reproducible public qualification evidence for the existing Project Ziwei fine-cycle **daily and hourly stem resolution**.

- profile: `ziwei-fine-cycle-lunar-late-zi-v1`
- rule version: `1.0-exp`

- Calendar Resolver remains neutral and owns legal local civil time, IANA timezone handling, DST gaps/ambiguity, Gregorian-to-lunar conversion, and civil hour branch.

- `00:00` on the following civil day does not double-advance.
- The hourly stem uses Five Rat from the already-resolved effective Ziwei day stem plus `CalendarContext.hour_branch`.
